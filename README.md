# 📒 Contact Book in C

A simple console-based **Contact Book** program written in **C**. This application allows users to add, view, search, and delete contacts using a user-friendly menu-driven interface.

---

## 🚀 Features

- ➕ Add a new contact (Name, Phone, Email)
- 📄 Display all saved contacts in a tabular format
- 🔍 Search for a contact by name
- ❌ Delete a contact by name
- 🔁 Menu-based interface with continuous user interaction until exit

---

## 🧠 Concepts Used

- Structures (`struct`) in C
- Arrays and strings
- Menu-driven program
- File handling (can be extended)
- Basic string manipulation (`strcmp`, `fgets`, `strcspn`)

---

## 🛠️ How to Run

1. **Save** the code as `contact_book.c`
2. **Compile** using any standard C compiler like `gcc`:

   ```bash
   gcc contact_book.c -o contactbook
   ```

3. **Run** the compiled program:

   ```bash
   ./contactbook
   ```
